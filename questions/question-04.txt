# 问题：内容文件必须提交到 Git 仓库才能部署

## 现状
CI 从 GitHub 仓库 clone 源码后执行 pnpm build。
如果 .md 内容文件不在 Git 仓库中（被 gitignore），CI 构建时 import.meta.glob 找不到文件，产物中就没有内容。

## 影响
- 内容文件强制绑定在代码仓库中，无法实现"内容与代码分离"
- 不适合非技术人员通过 CMS 编辑内容的工作流
- 仓库体积随着文章增加而增长（尤其是包含图片时）

## 改进方向
在 CI 构建步骤中增加一个"拉取内容"的阶段：
从独立的内容仓库 / GitHub Releases / 对象存储中 fetch .md 文件到 src/data/ 目录，然后再执行 vite build。
这样代码仓库只包含应用逻辑，内容仓库独立管理。
